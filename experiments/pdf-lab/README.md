# PaperBench PDF 独立验证

此目录保留 PDF 阅读器最初的隔离实验和验证脚本。通过验证的功能现已独立接入正式阅读界面，生产代码位于 `assets/pdf-reader/`。以下“隔离范围”和“尚未覆盖”描述实验阶段的状态，不代表当前正式版。批注、覆盖层、定位与实验页面代码自行实现；没有基于 NeoRead fork，也没有复制 NeoRead 或 PDF++ 的实现。底层使用 Mozilla PDF.js 官方 `PDFViewer`，本次验证版本为 `pdfjs-dist 5.6.205`。

## 隔离范围

- 没有修改正式 HTML、JS、CSS、C# 路由或构建脚本；没有重新构建或替换 PaperBench.exe。
- 独立本地服务只提供 GET/HEAD 文件读取，没有正式笔记、AI、导入或保存接口。
- PDF 通过手动文件选择，或启动参数指定的只读示例打开，不修改原文件。
- 批注仅存储到浏览器专用键 `paperbench.pdf-lab.v1:<PDF fingerprint>`。与正式 `review.annotations` 无关。
- 可导出实验 JSON；没有写回 PDF 功能。导出不是正式笔记格式。
- 自动化测试生成的 PDF、截图、报告在仓库已忽略的 `tests/runtime/pdf-lab/` 内。

## 打开实验页

```powershell
& .\experiments\pdf-lab\Start.ps1 -Pdf 'D:\path\to\paper.pdf'
```

打开终端输出的本机网址。点击“打开验证论文”，也可手动选择其他 PDF。`-Pdf` 可省略。

脚本默认使用本机 Codex 随附的 Node.js 和 pdfjs-dist；其他环境可用 `-NodePath`、`-PdfJsDirectory` 明确指定。依赖不通过外部 CDN 加载，也没有复制进正式程序。默认端口 18743，可用 `-Port` 修改；同一浏览器使用相同端口，才能读到同一份实验缓存。

## 实现要点

1. 使用官方 PDFViewer、配套 CSS、worker、字体资源、CMap 与 WASM；由阅读组件负责屏幕像素比和局部高清渲染。
2. SVG 覆盖层与页面画布共用页面表面坐标；屏幕像素比不进入批注坐标计算。
3. 保存页码、PDF 用户空间四边形，以及经过文本校验的 span 序号和字符范围。缩放后重新测量文字选区，消除字体取整导致的 1–2 CSS 像素误差；原始 PDF 坐标用于后备绘制和跳转。
4. 跨行与跨页按文字 span、页面分别拆分，不使用包围整段的单一矩形。
5. 阅读区域不继承中文界面的未知语言通用字体选择。PDF 提供语言时使用该语言，否则在本次 Chromium 验证中使用显式 `en` 回退，避免未嵌入 Helvetica 的选区宽度与 PDF 字体度量不同。
6. 文字锚点与 PDF.js 文字层结构有关，不能假定跨 PDF.js 版本仍保持同样的 span 编号；文本不匹配时回退到 PDF 坐标。正式接入前应增加版本与迁移约定。

## 已完成验证（2026-10-28）

使用独立无头 Chrome，屏幕像素比 1、1.25、2；四页测试 PDF 含已知文字坐标、双栏、裁剪框和原生旋转页。

通过的项目：100%/150%/200%/300% 缩放、拖动阅读区宽度、四个旋转方向、跨页返回、批注评论保存并刷新恢复、部分字符、多行独立矩形、跨页拆分、清空选区后不复用旧批注。

部分字符的 PDF 横坐标还与 PDF 字体宽度独立核对（容差 0.5 PDF 单位），避免覆盖层与错误的文字层一起偏移却“自测通过”。缩放/旋转后覆盖层与重新创建的原生选区边缘最大差为 0.0001221 CSS 像素；这是几何贴合结果，不代表所有字体的文字层都天然准确。

高清检查要求当前可见区域的实际渲染像素比达到对应屏幕像素比。在 300% 下，整页底图可以低分辨率，但必须有已完成的高清细节画布覆盖当前可见区域；不能只看整页 canvas 的尺寸作判断。

另用本地真实论文做 2× 高清屏渲染和标题批注截图检查，未发现明显模糊或高亮错位。没有做浏览器内置 PDF 阅读器的逐像素画质对照。

机器报告：`../../tests/runtime/pdf-lab/results.json`；截图同目录。

## 复现自动化验证

```powershell
$env:PDF_LAB_MODULES = 'C:\path\to\node_modules'
$env:PDF_LAB_SAMPLE = 'D:\path\to\paper.pdf' # 可选
node .\experiments\pdf-lab\verify.mjs
```

依赖：playwright、pdf-lib、pdfjs-dist、pngjs。默认使用已安装的 Windows Chrome，可用环境变量 `PDF_LAB_CHROME` 指定其他 Chromium 浏览器可执行文件。自动化使用随机端口，不接触手工体验页的缓存，退出时关闭测试浏览器和测试服务。

## 连续高亮与鼠标操作

- 高亮按视觉行合并相邻字体片段、引用和上下标，保留跨行与分栏间隔；去除片段边框。
- 全页高亮使用一个非零填充路径绘制，再统一应用透明度。重叠区域不会因反复绘制增加颜色深度。当前高亮使用统一浅黄色，激活状态显示在侧栏卡片中。
- 原始批注仍保留精确文字锚点与 PDF 坐标，视觉合并不改写原文选区；旧实验批注直接使用新显示方式。
- PDF 区域内 Ctrl＋滚轮按鼠标位置缩放；普通滚轮继续滚动。嵌套容器坐标换算避免工具栏高度导致缩放中心漂移。
- 按住中键拖动可沿两个方向平移；单击中键进入自动滚动，鼠标偏离起点越远滚动越快。再次单击、按键（含 Esc）或窗口失焦可停止。
- 增加混合字体与上下标、分栏隔离、实际像素叠色检查、Ctrl 滚轮中心定位、中键双向拖动与自动滚动停止测试。均在 1×、1.25×、2×屏幕环境验证交互；像素叠色对照在 1×运行。
