# 界面整理说明

- 顶栏：论文库开关、PDF／MD／对照、笔记、AI、沉浸模式（浏览器全屏，可再次点击或按 Esc 退出）。导入、打开文件夹、刷新与署名保留原位。
- 论文库：标题栏直接显示重复检查和标签管理，收起箭头位于最右；搜索后选择论文范围、目录／标签浏览和阅读状态。当前筛选显示为可清除的条件；浏览设置写入程序 settings.json，重启后恢复。
- 论文信息栏：三个阅读状态开关、收藏、标题与标签、附件、引用。更多菜单中保留打开论文目录与移至回收站。
- PDF 区域：翻页、缩放、查找与右侧的解析 PDF／更多／折叠合并为一条工具栏，去掉重复说明文字。解析 PDF 仍直接可点，后台自动准备 AI 可读正文；菜单保留精细解析、正文状态、精细解析成功后清理自动 TXT 的选项和 MinerU 位置设置。对照阅读时也能访问。
- 选中文字：批注、翻译、发给 AI 出现在选区旁。PDF 与正文各使用自己的选区工具条；图片选择仍支持发送 AI 与加入笔记。
- 笔记侧栏：笔记／批注／同时查看，右侧箭头收起侧栏；同时查看时，整篇论文笔记标题行显示空间分配开关，并排展开入口保留在笔记底部。点击正文批注、编辑批注或生成译文时自动显示批注。
- 收起区域不再留下竖向展开条，从顶栏原入口重新展开。实际展开的区域仍可拖动调整宽度。
- 导出阅读资料保留在左下角。

验证使用独立测试论文与测试状态，不修改真实论文库。新的界面检查位于 tests/quiet-interface.test.mjs；先构建 tests/runtime/pdf-integration/PaperBench.exe 并运行 PDF 集成检查准备测试资料，再运行界面检查。两项检查共用测试目录，应依次运行。沿用 PDF_LAB_MODULES 和 PDF_LAB_CHROME 环境变量。
