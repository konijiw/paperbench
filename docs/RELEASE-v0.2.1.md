# PaperBench v0.2.1

本次更新优化了论文阅读界面，并让只有 PDF 的论文也能自动准备 AI 可读正文。引用信息识别复用已有正文，无需另行配置 pdftotext。

## 更新内容

- 精简顶栏，统一 PDF／MD／对照切换，新增沉浸全屏；合并 PDF 工具栏并优化菜单与图标。
- 调整论文库筛选、笔记与批注布局，记忆分类浏览和筛选偏好。
- 首次打开只有 PDF 的论文时后台准备文字正文；已有 Markdown 或有效 TXT 则复用，PDF 更新后刷新过期的自动文本。
- 全文提问等待正文就绪并保留草稿；切换论文时取消待发送的问题，避免串到其他论文。
- 精细解析成功后优先使用 Markdown；TXT 默认保留，可按需清理程序生成且未被修改的 TXT。解析失败不清理原数据。
- 引用识别复用 Markdown／TXT，保留标题、作者与版本核验，无需安装外部 PDF 文字提取工具。
- 重整 README，区分主要能力、功能清单与按需使用场景。

## 下载与升级

下载 `PaperBench-Windows.zip`，将其中的 `PaperBench` 文件夹完整解压后运行 `PaperBench.exe`。运行环境为 Windows 10/11、.NET Framework 4.x 和现代浏览器。

升级前保存阅读内容并退出旧程序，再替换程序文件；保留自己的论文库以及 `state/`、`attachments/`、`prompts/`。压缩包不包含个人论文、阅读数据或 API 密钥。

MinerU 为可选外部工具。AI 功能使用已安装并登录的 Codex CLI，或自行配置 OpenAI 兼容 API。普通文字提取不执行 OCR；扫描件可使用精细解析，识别不足时仍可手动填写编号或导入 BibTeX。

`SHA256SUMS.txt` 提供下载包的 SHA-256 校验值。
