# PaperBench

面向科研文献的 **Windows 本地研读工作台**，整合文献管理、PDF 解析、批注笔记与 AI 对话，支持从论文收集、深入研读到引用与成果整理的完整流程。

**下载 Windows 版：** [PaperBench 便携 ZIP 包](https://github.com/konijiw/paperbench/releases/latest/download/PaperBench-Windows.zip) · [版本说明](https://github.com/konijiw/paperbench/releases/latest)

## 从文献管理到研读积累

- **面向研究主题的文献管理：** 批量导入论文，通过自定义标题、多标签与阅读状态建立分类，结合模糊检索快速查找相关文献。
- **PDF 解析与结构化内容提取：** 支持 PDF 文字提取，也提供对 MinerU（PDF 高精度解析工具）的原生支持，帮助提取论文中的正文、公式和图表，让 AI 更高效地阅读与分析论文。
- **可追溯的批注与图文笔记：** 关联原文摘录、批注内容与阅读笔记，结合图片和链接整理研究证据，支持从笔记定位原文，让阅读结论有据可查。
- **基于论文上下文的 AI 研读：** 原生支持 Codex，也可配置 OpenAI 兼容 API，围绕论文全文、选区和图表持续讨论，配合自定义提示词梳理方法、分析证据与拓展研究思路。
- **支撑材料关联与集中归档：** 将支撑论文、实验视频、代码和数据与主论文关联保存，便于在研读、复核与后续写作时统一查阅。
- **参考文献生成与阅读成果导出：** 自动识别书目信息，生成引用命令与参考文献；支持批量导出引用，以及包含论文、笔记和关联 AI 对话的阅读资料包，便于写作引用与成果留存。

完整功能见下方[功能一览](#功能一览)。

## 快速开始

### 1. 启动程序

需要 **Windows 10/11 和 .NET Framework 4.x**。

运行 `PaperBench.exe`，程序会启动本机服务，并在默认浏览器中打开阅读界面。

从上方下载 ZIP 包，将里面的 **`PaperBench` 文件夹整体解压**到可写的位置（例如 `D:\PaperBench`），再运行文件夹里的 `PaperBench.exe`。无需下载源码或安装 Python 即可使用基础阅读功能，请勿直接在压缩包内运行。

首次运行后，程序会在这个文件夹内自动创建 `state/`、`attachments/`、`prompts/`，保存配置、笔记、附件和提示词；论文文件保存在你选择的论文库。升级时先退出旧程序，只替换程序文件，保留自己的数据文件夹和论文库。

AI 对话默认使用已安装并登录的 Codex CLI，也可配置 OpenAI 兼容 API；PDF 精细解析需另行安装 MinerU；引用信息识别会复用已有的论文文字，无需额外配置 PDF 文字提取工具。这些是可选功能，不影响直接导入 PDF 阅读。开发者也可按下方的 [从源码构建](#从源码构建) 生成 EXE。

### 2. 选择论文库

点击右上角的 **“打开文件夹”**，选择一个用于存放论文的文件夹。之后可以：

- 将 PDF 拖到左侧论文库，直接复制入库；图片请拖到阅读笔记。
- 点击 **“导入论文 PDF”**，从不同文件夹累计选取文件，再批量导入。
- 打开已有的 MinerU 解析结果目录。

导入会保留原文件，为每篇论文建立独立目录。同名文件会自动避让；重复检查依据 PDF 文件内容，不只比较文件名。

### 3. 开始阅读

从左侧选择论文，即可阅读 PDF、记录整篇笔记、设置标签和阅读状态。

| 论文内容 | 可用的阅读方式 |
| --- | --- |
| 只有 PDF | 阅读 PDF，选字批注和 AI 翻译，保存整篇笔记，使用 AI 对话 |
| PDF 与 MinerU 解析结果 | PDF／Markdown 对照阅读，两种正文共用批注、翻译和笔记来源链接 |

只有 PDF 时，程序会自动在后台准备供 AI 使用的正文；已有解析结果则直接复用。相关能力见下方功能一览。

## 功能一览

### 文献管理与检索

- 批量导入 PDF、拖放入库，以及已有论文目录与 MinerU 解析结果的导入使用。
- 自定义标题、多标签分类、收藏及未读／粗读／精读状态管理。
- 目录浏览、标签浏览、模糊搜索，以及最近阅读、最新加入与阅读状态筛选；记忆浏览偏好。
- 标签管理、重命名与合并，重复论文检查与整理，支持移至系统回收站。

### 论文阅读与解析

- PDF、Markdown 与对照阅读，支持调整布局、折叠面板和沉浸全屏。
- 文内查找、跳页、缩放、旋转、中键平移与自动滚动，以及打开原始文件打印或下载。
- 自动提取 PDF 文字，为 AI 阅读准备正文；已有可用正文时直接复用。
- 提供对 MinerU（PDF 高精度解析工具）的原生支持，支持正文、公式、图表与图片的解析，并兼容已有解析结果。

### 批注与图文笔记

- 原文选区批注、AI 翻译、批注编辑与原文定位。
- 将摘录、批注和译文汇入笔记，保留来源链接，便于返回论文核对。
- 图文笔记支持正文图片、本地图片、粘贴截图与链接。
- 笔记阅读／编辑切换、格式工具和小结模板；支持笔记与批注同时查看、调整空间及并排展开。

### AI 研读与提示词

- 原生 Codex 支持，以及 OpenAI 兼容 API 配置。
- 围绕论文全文、文字选区、图片与 PDF 区域截图提问，支持连续对话和关联历史。
- 自定义提示词预设，支持调用、编辑、新建与删除。
- 可控制是否提供论文上下文，按论文管理对话；API 通道支持流式回答、图片与本地聊天历史。

### 支撑材料归档

- 关联支撑论文、PDF、实验视频、代码、Word 与数据文件，集中管理论文相关资料。
- 视频在阅读区域播放并支持全屏；支持直接选择并播放 ZIP 内的视频，无需手动解压。
- 其他附件可打开所在文件夹，交由相应软件处理。

### 引用与参考文献

- 自动识别书目信息，支持 DOI、arXiv 与标题查询，以及 BibTeX 导入、编辑与修正。
- 生成 BibTeX／BibLaTeX、LaTeX 引用命令及 Word 参考文献，支持按标签选择与批量导出。
- 提供常用参考文献样式，支持导入 CSL 样式、预览和复制；可撤销上一次书目信息覆盖保存。

### 阅读成果导出

- 批量选择论文，导出包含原文、解析内容、笔记及相关图片的阅读资料包。
- 可包含关联 AI 对话，便于归档、分享与独立阅读。

### 使用条件

基础阅读、批注、笔记和 PDF 文字提取不需要安装 MinerU。精细解析需另行安装 [MinerU](https://opendatalab.github.io/MinerU/quick_start/)；普通文字提取不执行 OCR，扫描件需使用相应解析方式。模糊检索不等于论文全文搜索。

AI 功能需安装并登录 [Codex CLI](https://developers.openai.com/codex/cli)，或配置 OpenAI 兼容 API。API 通道的图片支持取决于所选模型，不能替代 Codex 的文件工具与命令能力；使用 AI 时，相关内容会发送给所配置的服务。

视频播放取决于浏览器支持的格式与编码。引用识别复用论文文字；没有可用文字或识别不充分时，可通过 DOI、arXiv 或 BibTeX 补充信息。导出的对话档案用于阅读与归档，不用于恢复 Codex 会话。

安装与具体操作可参考[详细使用说明](docs/USAGE.md)。

## 数据保存与使用场景

### 单机阅读与本地备份

日常在一台电脑上阅读时，直接使用本地论文库即可，无需配置同步工具。升级程序或备份阅读成果时，请保留论文库和相关数据文件夹；备份前先保存笔记并退出程序。

| 内容 | 保存位置 |
| --- | --- |
| 论文 PDF、Markdown 和图片 | 你选择的论文库 |
| 阅读笔记、批注、标签、收藏与阅读状态 | `state/ai-literature-reader/papers/` |
| 书目信息与引用键 | `state/ai-literature-reader/citations/` |
| 论文加入时间记录 | `state/ai-literature-reader/paper-added/` |
| 附件副本及关联关系 | `attachments/` |
| 粘贴截图、拖入本地图片的笔记图片 | `attachments/_note-images/` |
| 提示词预设 | `prompts/` |
| 可重建的 PDF 搜索缓存 | `state/ai-literature-reader/pdf-search/` |

上表中的相对路径均以 `PaperBench.exe` 所在目录为起点。

### 如果需要在多台电脑上接续阅读

如果你希望在办公室、家中等不同电脑上接着阅读同一批论文，可以按需迁移数据，或使用自己已有的文件同步工具。PaperBench 不内置跨设备同步，也不要求使用指定的同步软件；没有这个需求时可跳过本节。

使用前请注意以下条件：

- **论文和阅读记录需要配套保留。** 仅复制 PDF 不会带上笔记、批注和标签。按需包含上表中的论文库、阅读记录、书目信息、入库时间记录、附件与提示词；搜索缓存可由各电脑重新生成。
- **各电脑保留自己的配置。** 不直接覆盖 `state/ai-literature-reader/settings.json`；在各电脑分别选择当地的论文库路径。使用相同版本，并保持论文库内部的相对目录结构一致。移动或重命名论文目录后，需要核对原有记录和引用关联。
- **附件与提示词目录应完整迁移。** 保留 `attachments/` 和 `prompts/` 内部的关联、初始化与删除记录，避免附件链接失效或已删除条目重新出现。预设菜单打开时会重新读取文件，也可手动刷新。
- **等待文件传输完成，再切换电脑编辑。** 程序不提供多人协作式的冲突合并；两台电脑同时修改同一篇论文的记录或同一条预设，仍可能产生冲突。编辑中的预设遇到外部更新时会提示并保留草稿，其他冲突需要自行核对。
- **AI 环境与部分偏好需要单独处理。** Codex 登录状态和完整聊天历史由 Codex 自身管理，不随上述文件夹自动迁移；论文与对话的绑定在更换根目录后也不保证自动匹配。自定义 API 密钥由当前 Windows 用户加密，换电脑或用户后需重新配置。浏览器本地保存的自定义 Word 样式和部分界面偏好不在上表的数据清单中。

## 从源码构建

在源码目录打开 PowerShell，运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1
..\PaperBench.exe
```

构建脚本会在源码目录的上一级生成 `PaperBench.exe`。网页资源、开源声明和相应的引用排版源码已嵌入程序，日常运行不需要单独复制源码中的 `assets/`。

更新时保留论文库、`state/`、`attachments/` 和 `prompts/`，不要用别人的个人数据覆盖它们。仓库不包含个人论文、阅读记录、登录信息或预编译 EXE。
